# ✅ To-Do List Web Application

## Overview

The To-Do List Web Application is a simple task management tool developed using HTML, CSS, and JavaScript. It helps users organize daily activities by allowing them to add, complete, and delete tasks through an interactive user interface.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Responsive and user-friendly design
* Dynamic task management using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## Project Structure

ToDoList/

├── index.html

├── README.md

## How to Run

1. Download the project files.
2. Open `index.html` in any web browser.
3. Add tasks using the input field.
4. Mark tasks as completed or delete them as needed.
